# DisKeyboard

Небольшое приложение для Windows (.NET 8 / WinForms), которое позволяет
включать и отключать клавиатуры. Полезно, когда у встроенной клавиатуры
ноутбука залипают клавиши: можно отключить её и пользоваться внешней
USB-клавиатурой.

## Возможности

- Показывает список всех клавиатур в системе.
- Рядом с каждой — галочка: снять, чтобы **отключить**; поставить, чтобы
  **включить**.
- **Аварийная блокировка ВСЕХ клавиатур** — гарантированно блокирует ввод
  даже у клавиатур, которые Windows не даёт отключить (см. ниже).
- Кнопка **X** сворачивает окно в трей (приложение продолжает работать).
- **ПКМ** по иконке в трее открывает меню: **Развернуть** /
  **Заблокировать все клавиатуры** / **Выход** (двойной клик по иконке
  также разворачивает окно).

## Три способа отключить клавиатуру

Windows помечает многие клавиатуры как «неотключаемые». Поэтому приложение
использует три механизма — от самого мягкого к самому надёжному:

1. **Отключение устройства** (для каждой клавиатуры отдельно). Клавиатурный
   узел почти всегда неотключаемый, поэтому приложение поднимается вверх по
   дереву устройств до ближайшего родителя, который Windows **разрешает**
   отключить (для USB-клавиатуры это её USB-узел — обычно на 2–3 уровня выше).
   Это надёжно работает для внешних USB-клавиатур и сохраняется после
   перезагрузки.

2. **Блокировка одной клавиатуры через реестр.** Для встроенной
   PS/2-клавиатуры, которую Windows не даёт отключить напрямую. Если просто
   снять галочку у такой клавиатуры, приложение прописывает её узлу
   несуществующий фильтр-драйвер (`UpperFilters` через
   `SetupDiSetDeviceRegistryProperty`), и PnP перестаёт запускать **только
   это** устройство. Тачпад (отдельный узел на том же контроллере i8042) и
   другие клавиатуры продолжают работать. Особенности: вступает в силу и
   снимается **после перезагрузки**, полностью обратимо (поставьте галочку
   обратно). Запись в реестр **проверяется** после изменения, а если что-то
   пойдёт не так — приложение покажет точный путь в реестре для ручной правки.
   Идеально, когда внешняя USB-клавиатура постоянно заменяет встроенную.

3. **Аварийная блокировка ВСЕХ клавиатур** (низкоуровневый перехват,
   `WH_KEYBOARD_LL`). Не зависит от типа устройства — просто «съедает» все
   нажатия и срабатывает мгновенно. Особенности: блокируются **все**
   клавиатуры сразу, снять блокировку можно мышью (галочка в окне или пункт в
   трее) либо комбинацией **Ctrl+Alt+End**. Действует только пока запущено
   приложение и не затрагивает защищённый рабочий стол (UAC, Ctrl+Alt+Del).

## Как пользоваться

Запусти приложение (оно попросит права администратора). В окне — список всех
клавиатур, у каждой галочка: **галочка стоит = клавиатура включена**.

### Отключить внешнюю USB-клавиатуру

1. Найди её в списке и **сними галочку**.
2. Готово — она отключается сразу, перезагрузка не нужна. Чтобы вернуть —
   поставь галочку обратно.

### Отключить встроенную клавиатуру ноутбука (например, при залипании клавиш)

Если у клавиатуры стоит пометка `нельзя отключить` — это встроенная
PS/2/HID-клавиатура, которую Windows не даёт выключить напрямую. Приложение
само отключит её через реестр:

1. **Сними галочку** у встроенной клавиатуры.
2. Подтверди в появившемся окне (там сказано, что затрагивается только эта
   клавиатура; тачпад и другие клавиатуры продолжат работать).
3. В списке появится пометка `реестр: блок после перезагрузки`.
4. **Перезагрузи компьютер.** После перезагрузки встроенная клавиатура не
   работает, а тачпад и внешняя USB-клавиатура — работают.

**Вернуть встроенную клавиатуру обратно:**

1. Открой приложение, **поставь галочку** обратно у той же клавиатуры.
2. Подтверди.
3. **Перезагрузи компьютер** — клавиатура снова работает.

> Если по какой-то причине запись в реестр не удалась, приложение покажет
> точный путь в реестре (`HKLM\SYSTEM\CurrentControlSet\Enum\…\UpperFilters`),
> где нужно удалить строку `DisKeyboardNull`, чтобы включить клавиатуру вручную.

### Резервная копия реестра и восстановление вручную

Реестровая блокировка меняет ровно одно значение — `UpperFilters` в ветке
устройства. Рекомендуется на всякий случай сохранить эту ветку **до**
блокировки и знать, как снять блокировку руками (например, если включить
обратно нужно с другого компьютера или из среды восстановления).

**Шаг 1. Узнать точный путь устройства.**

1. `Win+X` → **Диспетчер устройств** → раздел **Клавиатуры**.
2. ПКМ по нужной клавиатуре → **Свойства** → вкладка **Сведения**.
3. В списке выбери **«Путь к экземпляру устройства»** — получится строка вида
   `ACPI\PNP0303\4&...&0`, `ACPI\MSFT0001\4&...&0` или `HID\VID_...\...`.
4. ПКМ по значению → **Копировать**.

Полный путь в реестре:

```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Enum\<путь к экземпляру устройства>
```

**Шаг 2. Сохранить резервную копию ветки (до блокировки).**

1. Открой `regedit`, вставь путь из шага 1 в адресную строку, нажми Enter.
2. ПКМ по выделенному разделу слева → **Экспортировать** → сохрани `.reg`-файл.
   В нём останется исходное состояние, в т.ч. отсутствие/наличие
   `UpperFilters`. Восстановить — двойной клик по `.reg` (или **Файл →
   Импорт**) и перезагрузка.

> Можно сохранить и всю ветку `...\CurrentControlSet\Enum` целиком, но точечный
> экспорт конкретного устройства надёжнее и быстрее восстанавливается.

**Шаг 3. Снять блокировку вручную (если приложение недоступно).**

1. Перейди по пути из шага 1.
2. Найди значение **`UpperFilters`** (тип `REG_MULTI_SZ`).
3. Если в нём **только** строка `DisKeyboardNull` — удали значение
   `UpperFilters` целиком (ПКМ → Удалить). Если есть и другие строки —
   двойной клик и убери только строку `DisKeyboardNull`, остальные оставь.
4. **Перезагрузи компьютер.**

> Не нашёл значение по этому пути? Активным может быть другой набор —
> проверь то же самое в `...\SYSTEM\ControlSet001\Enum\...`. Либо в regedit
> выдели ветку `HKEY_LOCAL_MACHINE\SYSTEM`, нажми **Правка → Найти**, включи
> галочку **«Данные»** и найди `DisKeyboardNull` (F3 — следующее вхождение).

### Мгновенно заблокировать ввод (разовая ситуация)

Например, чтобы протереть клавиатуру или когда на неё лезет кот:

1. Поставь галочку **«Аварийная блокировка ВСЕХ клавиатур»** внизу окна
   (или пункт **«Заблокировать все клавиатуры»** в меню трея).
2. Все клавиатуры мгновенно перестают вводить символы.
3. Снять блокировку: мышью сними ту же галочку / пункт в трее, **либо** нажми
   на клавиатуре **Ctrl+Alt+End** (эта комбинация всегда работает).

> Блокировка действует только пока приложение запущено и не затрагивает
> защищённый рабочий стол (UAC, экран входа, Ctrl+Alt+Del).

### Свернуть в трей

Кнопка **X** не закрывает приложение, а прячет окно в трей (значок у часов).
**Двойной клик** по значку — развернуть; **ПКМ** — меню (Развернуть /
Заблокировать все клавиатуры / Выход). Кнопка **«Обновить список»**
перечитывает клавиатуры, если ты подключил/отключил устройство.

## Требования

- Windows 10/11.
- .NET 8 SDK для сборки.
- **Права администратора** — включение и отключение устройств требует
  повышения привилегий, поэтому приложение запросит UAC при запуске
  (см. `app.manifest`).

## Сборка и запуск

```powershell
dotnet build -c Release
dotnet run -c Release
```

> Сборка и запуск возможны только под Windows: проект нацелен на
> `net8.0-windows` и использует Windows Forms + SetupAPI.

## Как это работает

Перечисление клавиатур и переключение их состояния выполняется через
Windows SetupAPI (`SetupDiGetClassDevs`, `SetupDiCallClassInstaller` с
`DIF_PROPERTYCHANGE`) и Configuration Manager (`CM_Get_DevNode_Status`,
`CM_Get_Parent` для подъёма по дереву устройств). Блокировка одной
клавиатуры через реестр прописывает узлу `UpperFilters`
(`SetupDiSetDeviceRegistryProperty`). Аварийная блокировка реализована
низкоуровневым хуком клавиатуры (`SetWindowsHookEx` с `WH_KEYBOARD_LL`),
который отбрасывает все нажатия.
