# DisKeyboard

Небольшое приложение для Windows (.NET 8 / WinForms), которое позволяет
включать и отключать клавиатуры. Полезно, когда у встроенной клавиатуры
ноутбука залипают клавиши: можно отключить её и пользоваться внешней
USB-клавиатурой.

## Возможности

- Показывает список всех клавиатур в системе.
- Рядом с каждой — галочка: снять, чтобы **отключить**; поставить, чтобы
  **включить**.
- **Аварийная блокировка ВСЕХ клавиатур** — гарантированно блокирует ввод
  даже у клавиатур, которые Windows не даёт отключить (см. ниже).
- Кнопка **X** сворачивает окно в трей (приложение продолжает работать).
- **ПКМ** по иконке в трее открывает меню: **Развернуть** /
  **Заблокировать все клавиатуры** / **Выход** (двойной клик по иконке
  также разворачивает окно).

## Два способа отключить клавиатуру

Windows помечает многие клавиатуры как «неотключаемые». Поэтому приложение
использует два механизма:

1. **Отключение устройства** (для каждой клавиатуры отдельно). Клавиатурный
   узел почти всегда неотключаемый, поэтому приложение поднимается вверх по
   дереву устройств до ближайшего родителя, который Windows **разрешает**
   отключить (для USB-клавиатуры это её USB-узел — обычно на 2–3 уровня выше).
   Это надёжно работает для внешних USB-клавиатур и сохраняется после
   перезагрузки.

2. **Аварийная блокировка ВСЕХ клавиатур** (низкоуровневый перехват,
   `WH_KEYBOARD_LL`). Встроенную PS/2-клавиатуру отключить нельзя: её
   контроллер i8042 обслуживает ещё и тачпад, и Windows запрещает его
   отключение. Перехват же не зависит от типа устройства — он просто
   «съедает» все нажатия. Особенности: блокируются **все** клавиатуры сразу,
   снять блокировку можно мышью (галочка в окне или пункт в трее) либо
   комбинацией **Ctrl+Alt+End**. Блокировка действует только пока запущено
   приложение и не затрагивает защищённый рабочий стол (UAC, Ctrl+Alt+Del).

## Требования

- Windows 10/11.
- .NET 8 SDK для сборки.
- **Права администратора** — включение и отключение устройств требует
  повышения привилегий, поэтому приложение запросит UAC при запуске
  (см. `app.manifest`).

## Сборка и запуск

```powershell
dotnet build -c Release
dotnet run -c Release
```

> Сборка и запуск возможны только под Windows: проект нацелен на
> `net8.0-windows` и использует Windows Forms + SetupAPI.

## Как это работает

Перечисление клавиатур и переключение их состояния выполняется через
Windows SetupAPI (`SetupDiGetClassDevs`, `SetupDiCallClassInstaller` с
`DIF_PROPERTYCHANGE`) и Configuration Manager (`CM_Get_DevNode_Status`,
`CM_Get_Parent` для подъёма по дереву устройств). Аварийная блокировка
реализована низкоуровневым хуком клавиатуры (`SetWindowsHookEx` с
`WH_KEYBOARD_LL`), который отбрасывает все нажатия.
